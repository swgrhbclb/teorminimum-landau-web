Теоретический минимум Ландау

Теоретический минимум Ландау состоит из 11 экзаменов по основным разделам математики и теоретической физике. Сдавать экзамены может любой желающий в произвольном порядке.
Для сдачи каждого экзамена нужно в индивидуальном порядке договориться с соответствующим экзаменатором. Экзамены по теоретической физике даются по материалу курса «Теоретическая физика» Л.Д. Ландау и Е.М. Лифшица в объеме, указанном на странице соответствующего экзамена. Некоторые экзамены Теоретического минимума входят в обязательную учебную программу для студентов кафедры Проблемы теоретической физики МФТИ.
